# 官方就业信息源覆盖说明

更新时间：2026-09-06

## 覆盖结论

- 账号基线：60 个公众号，清单见 `app/presets/official_accounts.json`。
- 可运行官网覆盖：45 个账号；多个复旦学生组织账号复用同一校级就业源，避免重复入库。
- 阻断但已审计：15 个账号；均记录 `reason` 和 `alternative`，没有遗留 `probe` 状态。
- 爬虫配置：41 个来源配置，见 `app/presets/official_sources.json`。
- 自动校验：`testCoverAccounts` 要求账号数量和 fakeid 唯一、所有来源属于账号基线、每个已接入账号能映射到来源、每个阻断账号同时具备原因和替代入口。

## 已接入能力

官网爬虫支持静态 HTML、分页 HTML、动态压缩 HTML、公开 JSON API、JYXT、91JOB/Career 列表、复旦就业公开 API、人大公开内容 API、哈工大公开通知 API、电子科大和中科大专用 API。所有来源统一执行日期过滤、链接去重、正文 Markdown 归档、SQLite 记录、运行状态和每日增量。
